# 🎬 CineMax - Full Stack Multiplex Management System

> A modern, full-stack multiplex management and movie ticket booking web application built with React, Node.js, Express, MongoDB, and Socket.io.

🌐 **Live Website**: [https://cinemax-plex.vercel.app](https://cinemax-plex.vercel.app)  
📡 **Production API**: `https://multiplex-management-system-1.onrender.com`

---

## ✨ Features

- 🎟️ **Movie Ticket Booking**: Browse latest movies, select dates, view showtimes, interactive seat layout, and book tickets.
- ⚡ **Real-Time Seat Locking**: Socket.io integration to prevent double booking of seats in real-time.
- 🏢 **Multi-Theatre & Multi-Screen Support**: Automatic screen generation and management for newly added theatres.
- 📅 **Show Scheduling**: Admin & Theatre Owner dashboard to schedule shows across theatres and screens.
- 🔐 **Authentication & Roles**: JWT-based authentication with role-based access control (User, Theatre Owner, Admin).
- 📧 **Password Reset & OTP**: Secure OTP-based password recovery via email service.

---

## 🛠️ Tech Stack

- **Frontend**: React (Vite), React Router, React Hot Toast, Vanilla CSS
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), Socket.io
- **Deployment**: Vercel (Frontend), Render (Backend API)
